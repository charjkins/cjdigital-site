# CJ Digital

Portfolio site for CJ Digital: short animated launch and promo videos by Charlie Jenkins.

Live at https://cjdigital.uk

- `index.html` – the whole site: particle intro, globe and Bedford map, film list and contact
- `v/` – videos, web-quality MP4
- `p/` – poster frames for each video, plus Charlie's photos
- `s/` – six-frame filmstrips used in each film's case file

Static site, no build step. Hosted on Cloudflare Pages.
